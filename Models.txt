# OpenCode does not include Qwen3 Coder by default. 
# You first need to install a local runtime (such as Ollama) and then connect OpenCode to it.
   * OpenCode is the interface.
   * Ollama is the runtime.
   * Qwen3 Coder is the model.


Model Creator 	= Company that built the model
Runtime 	= Software that runs a local model
Cloud Provider 	= Online service that gives access to a model

Model Creator: 	Builds and trains the AI model (e.g., Alibaba for Qwen3 Coder).
Runtime: 	Executes the model on your machine (e.g., Ollama, LM Studio).
Application: 	Provides the user interface and workflows (e.g., OpenCode, VS Code extensions, chat applications).



For Example:
Qwen3 Coder 	= Model
Alibaba Cloud 	= Model creator
Ollama 		= Local runtime
OpenCode 	= Coding application
