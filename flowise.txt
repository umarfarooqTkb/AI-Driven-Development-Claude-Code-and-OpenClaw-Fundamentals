What is flowise
++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++
- Flowise is an open-source visual AI workflow builder that lets you create chatbots, AI agents, RAG systems, and LangChain workflows without writing much code.

Flowise
├── Prompt
├── LLM
├── Memory
├── Vector database
├── Documents
├── Tools
└── Agent logic

Method 1: Install Flowise Using NPM (Recommended)
++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++
Check versions & Verify
node -v
npm -v

which node
which npm
which npx


Step 1: Install Flowise
- npm install -g flowise

Step 2: Start Flowise
- npx flowise start
or
- flowise start


Step 3: Access Flowise
Open:
http://localhost:3000

Default login:
Username: admin
Password: admin



Method 2: Run Without Installation
++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++
npx flowise start

This downloads and runs Flowise temporarily.


Method 3: Docker Installation
++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++
Pull Image
- docker pull flowiseai/flowise

Run Container:
docker run -d \
--name flowise \
-p 3000:3000 \
flowiseai/flowise


Access:
http://localhost:3000




Method 4: Docker Compose (Production)
++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++
- Create docker-compose.yml

version: "3"
services:
  flowise:
    image: flowiseai/flowise
    container_name: flowise
    restart: always
    ports:
      - "3000:3000"
    volumes:
      - ./flowise:/root/.flowise
      
Start:
docker compose up -d






Flowise Uninstallation
++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++

Step 1: Add your API credential:

Step 2: Create your first Agentflow

Step 3: Add Start node
Click the + button or right-click on canvas.
Search Start.
Add Start Node.

This is where the user message enters the flow.



Step 4: Add Agent node
Click + again.
Search Agent.
Add Agent Node.
Connect Start → Agent.

Click the Agent node and set:

Max Tokens: 	1000

You are a helpful customer support agent. 
Answer clearly and politely.
If you do not know the answer, say that you are not sure.
Keep answers short and practical.


Step 6: Add End node
Add End Node.
Connect Agent → End.
Your basic flow should look like: Start → Agent → End

Click Save.

Flowise Step by Step: Creating Agent for Document Store (RAG) - 15June2026 - Learning Level 2

++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++
++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++
- Flowise Cloud + Gemini + Pinecone
- Do not use Chroma or local Flowise now.
- Flowise recommends Document Stores for RAG because they manage uploading, chunking, upserting, and syncing documents in one place.
- You can use any LLM instead of Gemini.
- You can use any Vector database instead of Pinecone



Pre-Requisites: Create following accounts
1. Create Flowise cloud account				# https://cloud.flowiseai.com/
2. Create Gemini API key				# Google AI Studio >> https://aistudio.google.com/
3. Create Pinecone account + API key			# https://app.pinecone.io/



Step 0: Create API Key of your platform (OpenAI, Gemini, Anthropic etc):
- For Gemini  =  Google AI Studio  >> aistudio.google.com
- For ChatGPT =  Open AI Platform  >> platform.openai.com
- Click on API Keys / Create API Key



Step 2: Create Pinecone index
- In Pinecone cloud portal, create an index: Click on "Create index"
- Index name: scrum-kb-gemini
- Select custom settings
- Vector type: Dense
- Dimension: 3072
- Metric: cosine
- Capacity mode: Serverless (On-Demand)
- Cloud: AWS
- Region: us-east-1
- click on "Create index"
Important:
- Do NOT select llama-text-embed-v2
- Because that model created a 2048 dimension index.
- You need a custom/dense index with: Dimension: 3072


Step 3: Add credentials in Flowise Cloud (Google API Key and Pinecone API Key)
- Go to: Credentials → Add Credential → Select Google Generative AI
- Credential Name	= Type any Name
- Google AI API Key	= Paste API Key generated in above step 0/Pre-Requisites
- Repeat above steps for Pinecone API Key



Step 4: Create Document Store in flowise
- In Flowise, Go to: Document Stores → Add New
- Name 		= Scrum Knowledge Base
- Description	= Optional
- Click on Add →  Add Document Loader 
- Select Document Loader = PDF File
- Click on "Upload File". Upload only one small PDF first, for example: 2020 Scrum Guide.pdf
- Do not upload many files at the start.
- Click on Process Button
- Click Refresh button after few seconds/mins
- A green icon should appear at the start of record.
- Overall status should be = SYNC



Step 5: Configure Upsert (Upsert Document)
- Open the uploaded PDF row: Options →  Upsert Chunks
- Select: Embeddings  = Google Gemini Embedding
- Connect Credential  = Select Gemini API Key from dropdown
- Model Name	      = gemini-embedding-001
- Task Type	      = RETRIEVAL_DOCUMENT
- Click on Select Vector Store:
- Vector Store 	      = Pinecone
- Connect Credentials = select pineconeAPI Key from dropdown
- Index Name  	      = scrum-kb-gemini
- Pinecone Namespace  = leave as blank
- Top K		      = 4
- Click on "Save Config" then click on Upsert
- Upsert Record dialog box will appear
- Click on "Test Retrieval" button.
- UPSERTED status in GREEN color should be displayed at the top of DOcument Store.
- Upsert means Flowise converts your document chunks into vectors and stores them in Pinecone for RAG.

Wait until the status changes from: UPSERTING to something like: SYNC or UPSERTED
or the loading stops.
Do not click Upsert again while it is still processing.

Note:
- Vector database and embedding model must match.
  Gemini embedding → 3072 dimensions
  Pinecone index → must also be 3072



Step 6: Test Retrieval
- Before creating the agent, test the knowledge base.
- After upsert: Go to Document Store → Scrum Knowledge Base  →  More Actions → Retrieval Query
- Ask: What is a Sprint Goal?
- Click on Search icon
- If it returns chunks from the Scrum Guide, your knowledge base is working.


Step 7: Create the RAG Agent
- Now create the actual agent.
- In Flowise, Go to: Agentflows → Add New
- Choose: Agentflow V2  → Click Save
- Name =  Scrum Knowledge Agent


Step 8: Add Agent Node
- On the canvas: Click + → Add Agent
- Then connect:  Start → Agent (Scrum Knowledge Agent)


Step 9: Configure Agent Model
- Double-click on Agent Node.
- Click on Pencil icon to set the name of agent, if not already not done. Scrum Knowledge Agent
- For Model, choose your chat model, for example: Google Gemini (i selected) or OpenAI or AWS Bedrock or Azure OpenAI or Anthropic Claude etc etc.
- Click on Google Gemini Parameters dropdown
- Connect Credential = Select your API Key  		# created in Step 1
- Model Name = Select Models of Gemini  		# as per your requirement
- Temperature = .4					# by default .9, change as per your requirement
- Input Message
  You are a Scrum Knowledge Agent.
  Answer user questions using the uploaded Scrum Knowledge Base.
  Use the Scrum Guide as the main source.
  Explain answers in beginner-friendly language.
  If the answer is not found in the uploaded documents, say:
  "I could not find this in the uploaded Scrum documents."
  Keep answers clear, structured, and practical.
  
Important Note:
 * Embedding model = for documents
 * Chat model = for answering users



Step 10: Attach Knowledge Base
- Inside the same Agent node properties, click:  "+ Add Knowledge (Document Stores)"
- Select: Already created Document Store. in this case (Scrum Knowledge Base)
- Describe Knowledge:

If the answer is not found in this knowledge base, say that the information was not found in the uploaded Scrum documents.
  
  
- Turn on: Return Source Documents		# if available. This helps you see which document chunks were used.
  Keep Return Source Documents enabled, as you already did. That will help you verify whether the agent is really using your uploaded Scrum PDF.

- Then click Save and test with:

Flowise Troubleshooting
++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++
++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++
- A large txt file was upload in document store, and stuck in "Upsert Chunks" process.
- Flowise tried to process one huge text file as one giant chunk, so it got stuck.

- Go back to Flowise >> Document Store >> select the file, creating problem >> click: options -> Delete
- Do not delete the whole Document Store. Only delete the TXT file loader.
- Then upload the TXT file again, but this time add a splitter.
- Use: 
  Recursive Character Text Splitter in Splitter settings
  Chunk Size: 1500
  Chunk Overlap: 200
- After processing, it should not show: Chunks: 1
- It should show something like: Chunks: 100+ or more
- Then click:
   Options → Upsert Chunks
   Save Config → Upsert
- After successful upsert, Pinecone record count should increase from: 30 to something higher, like 130, 200, 250, 500
  depending on how many chunks Flowise creates.
