# Acme Follow-Up Starter

Sample sources for the "Your first real task" walkthrough in
the Cowork & OpenWork crash course.

## What's here
- `acme-call-notes.md` — rep's notes from a discovery call
- `acme-chat-thread.md` — questions the prospect asked in chat

## What to do
1. Open this folder in Cowork or OpenWork (granting folder access).
2. Paste the prompt from the chapter (the one that starts
   "I had a sales call with Acme yesterday").
3. Watch the plan, approve, watch the execution, review the draft.

The agent will create `acme-followup.md` here when it's done.
