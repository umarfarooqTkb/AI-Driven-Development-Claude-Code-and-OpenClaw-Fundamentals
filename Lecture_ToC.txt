** Undo or Rewind Changes in Claude Code and OpenCode ***
--------------------------------------------------------------------------------------------------------------------------------------------------------------
Both Claude Code and OpenCode provide features to restore an earlier conversation state and reverse code changes.

Claude Code:
Claude Code uses checkpointing. It automatically creates a checkpoint before each user prompt and tracks changes made through Claude’s file-editing tools.

Open the Rewind Menu
Use either:
/rewind
Or press:
Esc, Esc

Press the Esc key twice while the prompt input is empty.
If text is present in the prompt, pressing Esc twice clears the text instead of opening the rewind menu.

Rewind Options
After selecting a previous checkpoint, Claude Code provides the following options:
Restore code and conversation
Revert both the code changes and conversation to the selected checkpoint.
Restore conversation
Rewind the conversation while keeping the current code changes.
Restore code
Revert code changes while keeping the full conversation.
Summarize from here
Compress the conversation from the selected point onward to free context-window space.
Summarize up to here
Compress the earlier conversation while keeping the newer messages.
Important Limitations

Claude Code rewind does not necessarily restore:

Files changed through Bash commands such as rm, mv, cp, or shell redirection
Changes made by background subagents
Manual changes made outside Claude Code
Changes from another Claude Code session
Symlinked or hard-linked files

Therefore, Claude Code checkpointing should be treated as a session-level undo feature, not as a replacement for Git.


OpenCode

OpenCode provides the /undo command.

Undo the Last Interaction
/undo
This removes:
The most recent user message
OpenCode’s responses after that message
Associated file changes

It also restores the original prompt so that you can edit and submit it again.

You can run /undo multiple times to move further back through the conversation.


Keyboard Shortcut
Ctrl+X, then U


Redo an Undone Interaction
/redo
Keyboard shortcut:
Ctrl+X, then R
/redo restores the previously undone conversation and file changes.

Important Limitation
OpenCode uses Git internally to restore file changes. Therefore, the project should be inside a Git repository for reliable file restoration.


Simple Summary
Claude Code:
Esc + Esc → Select checkpoint → Restore code, conversation, or both
/rewind

OpenCode:
/undo
/redo

how to identify context rot situation
-------------------------------------------------------------------------------------------------------------------------------------------------
- AI will take instruction from you  but will not do the changes and keep saying sorry
- AI will keep you sending the same response again and again
- AI forgets a rule, which you told earlier

# in such situations, stop sending messages to AI, you will waste your tokens or usage limit
