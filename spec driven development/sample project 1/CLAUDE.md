# CLAUDE.md

## Principles
- One page, one purpose: instant quote calculator for dog-walking services
- Owner and customers use the same tool — no hidden complexity
- Works offline after first load; no network dependency

## Constraints
- Single HTML file with embedded CSS/JS only
- No backend, database, login, external APIs, or frameworks

## Definition of Done
- Calculator produces accurate quotes for all service tiers
- Page loads and functions without internet
- Owner can update prices by editing one config object in the file
